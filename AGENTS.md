# AGENTS.md

This repository is a web MCP demo. Keep agent guidance concise, practical, and aligned with the project as it grows.

## Working rules

- Inspect the repository and existing documentation before making changes.
- Preserve unrelated user changes; modify only files relevant to the requested task.
- Prefer small, focused edits and use the project’s existing conventions.
- Never commit secrets, credentials, tokens, or private environment files. Use examples or placeholders instead.
- Update relevant documentation when behavior, setup, commands, or project structure changes.
- Run the most relevant available checks after making changes and report anything that could not be verified.
- Keep file paths, commands, and documentation accurate as the project evolves.
- If a task is blocked, explain the concrete blocker and avoid making speculative changes.

## Completion checklist

- Review the final diff for unrelated changes.
- Run available tests, linters, type checks, or builds that apply to the change.
- Confirm no secrets or generated artifacts were added accidentally.
- Summarize the changes and verification results clearly.
